# Third-Party Licenses

This document lists all third-party dependencies used in this project and their respective licenses.

## License Compliance Notice

This project uses dependencies with various open-source licenses. Some dependencies use the BSD-2-Clause license, which has been flagged for review according to organizational license policy (Alert: SB-LICENSE-POLICY-VIOLATION).

**Compliance Requirements:**
- SOC 2 (CC6.1): Organizations must protect themselves from unauthorized information disclosure, including adherence to software licensing agreements
- GDPR (Article 32): Requires appropriate security measures; license violations can compromise data protection
- NIST SP 800-53 (CM-10): Software Usage Restrictions - use software in accordance with contract agreements and copyright laws
- FedRAMP (CM-10): Software Usage Restrictions
- ISO 27001 (A.8.1.1): Inventory of Assets - proper asset management and control

## BSD-2-Clause License Terms

The BSD-2-Clause license is a permissive open-source license that:
- ✅ Allows commercial use
- ✅ Allows modification
- ✅ Allows distribution
- ✅ Allows private use
- ⚠️ Requires attribution (copyright notice and license text)
- ⚠️ Includes disclaimer of warranty
- ❌ Does NOT provide patent grant (unlike Apache-2.0)
- ❌ Does NOT provide trademark rights

## Compliance Verification

To verify license compliance:

```bash
# Install go-licenses tool
go install github.com/google/go-licenses@latest

# Check all licenses
go-licenses report github.com/northwesternmutual/grammes

# Check for specific license types
go-licenses check github.com/northwesternmutual/grammes --disallowed_types=forbidden,restricted
```
